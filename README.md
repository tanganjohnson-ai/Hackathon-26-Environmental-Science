# Hackathon-26-Environmental-Science
GitHub Hackathon 26 will develop an accessible urban heat CURE for UFOR 271 at Southern University. Students will use CloudBank Classroom and scaffolded notebooks to discover, visualize, analyze, and interpret Baton Rouge environmental data. GitHub will support reusable and reproducible course resources.
# FacultyHack@Gateways 2026 Curriculum Project

## Project Overview
This project updates UFOR 271B: Environmental Science (From the Bluff to the Bayou: Environmental Science for Resilient Communities) at Southern University and A&M College[cite: 2, 3]. The primary goal is to integrate ACCESS CloudBank Classroom (a managed teaching JupyterHub), HPC Carpentry, and Science Gateway datasets to guide 10–15 undergraduate students through a 4-step Course-based Undergraduate Research Experience (CURE) focused on urban heat, land cover, and environmental resilience in Baton Rouge and South Louisiana[cite: 2, 3].

## Science Gateway Resources & Technology Notes
The curriculum module incorporates browser-based computing and science gateways to ensure low-barrier, equitable student access without local software installation[cite: 2, 3].

### Tools Used
**ACCESS CloudBank Classroom** [https://cloudbank.org](https://cloudbank.org)[cite: 2, 3]
*   **Description:** A managed teaching JupyterHub that provides campus-credential login, persistent student storage, browser-based tools, and instructor-supported assignment workflows[cite: 3].
*   **Course Use:** Serves as the primary course science-gateway environment for running Jupyter Notebooks and executing CURE data analysis workflows[cite: 2, 3].

**HPC Carpentry (Introduction to HPC)** [https://hpc-carpentry.github.io](https://hpc-carpentry.github.io)[cite: 2, 3]
*   **Description:** An introductory training framework establishing foundational concepts and vocabulary for high-performance and remote computing.
*   **Course Use:** Acts as an onboarding module to prepare students for remote computing resources, file navigation, and responsible data management practices[cite: 2, 3].

**Leafmap / Geemap** [https://leafmap.org](https://leafmap.org)[cite: 3]
*   **Description:** Open-source Python packages for interactive geospatial analysis and visualization in Jupyter environments[cite: 3].
*   **Course Use:** Used during CURE Activity 2 (Visualization) to generate interactive maps of Baton Rouge land cover, surface temperature, and urban heat distribution[cite: 2, 3].

**OpenTopography / HazMapper / ScienceGateways.org Catalog** [https://sciencegateways.org](https://sciencegateways.org)[cite: 3]
*   **Description:** Public science gateway platforms providing access to high-resolution elevation/LiDAR datasets, collaborative geotagged observation mapping, and domain database catalogs[cite: 3].
*   **Course Use:** Applied during CURE Activity 1 (Discovery) and Activity 4 (Interpretation) to retrieve local environmental data and organize geotagged field measurements[cite: 3].

### Implementation Notes
*   *Session 1:* Onboarded students to ACCESS CloudBank Classroom via campus credentials and conducted HPC Carpentry orientation to establish shared computing vocabulary[cite: 3].
*   *Session 2:* Tested CURE Activity 1 (Discovery) and Activity 2 (Visualization) workflows using OpenTopography datasets and leafmap interactive mapping notebooks[cite: 3].
*   *Session 3:* Evaluated CURE Activity 3 (Analysis) and Activity 4 (Interpretation) tools, including spreadsheet CSV fallbacks and HazMapper integration for geotagged field observations[cite: 3].
